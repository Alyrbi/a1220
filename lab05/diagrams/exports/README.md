# Diagram exports

Open an SVG in a browser to zoom into the labels, or open its matching PDF. Each file contains one view, with the same base name as its editable DOT source.

1. `01-context`: the system, its users and external systems.
2. `02-containers`: Web UI, Board API and Board Database.
3. `03-components`: the six components inside Board API.
4. `04-code`: types, responsibilities and interfaces inside Reservation Rules.
5. `05-dynamic`: Ari's reservation and the mail outage, numbered from 1 to 24.

The larger diagrams are vector pages intended for zooming; keep them at their original size when viewing. Student details, file mapping and requested notes are in `../../DESIGN.md`.
